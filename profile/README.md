Drift Creative Systems builds focused software for working musicians, venues, festivals and the small businesses around them. We're a small, independent studio based in Devon, UK, building on a stack we know well: WordPress, ACF, PHP and vanilla JavaScript, with progressive web apps where one codebase across Android, iOS and desktop makes more sense than three.

## Products

| Product | What it does | Status |
|---|---|---|
| **Drift: Surface** | Band and artist websites, managed from one hub so labels and managers can update every artist in one place | Launching |
| **Drift: Record** | A personal gig and festival tracker: log what you've seen, plan what's next | Launching |
| **Drift: Flow** | Private gig management for working DJs and bands: bookings, fees, travel, set notes and income | In development |
| **Drift: Control** | Venue and promoter tools, including listings-to-social automation | In development |
| **Drift: Live** | White-label festival app, delivered as a PWA: no app store install required | In development |

## How we build

- **Small and maintainable.** Plain PHP, jQuery and vanilla JS over heavy frameworks.
- **WordPress done properly.** ACF Pro, WordPress Coding Standards, escaped output, nonces and capability checks throughout.
- **PWAs where they fit.** Installable, offline-capable, one codebase.
- **Validated before built.** We prototype with real users before committing to features.
